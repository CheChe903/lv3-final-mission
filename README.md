# 식당 테이블링 서비스

## 사용자 예약

- [x] 사용자는 식당을 검색할 수 있다.
- [x] 사용자는 식당을 하나만 예약할 수 있다.
- [x] 사용자는 자신의 예약 순번을 알 수 있다.
- [x] 사용자는 식당이 임시 닫음, 닫음 상태에서는 예약할 수 없다.
- [x] 사용자는 공휴일에 테이블링을 할 수 없다.
- [x] 사용자는 자신의 테이블링을 취소할 수 있다.

## 가게 주인

- [x] 가게 주인은 식당을 하나 등록할 수 있다.
- [x] 가게 주인은 식당 상태를 변경할 수 있다.
